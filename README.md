# Responsive Portfolio Website

## 📌 Project Description
A fully responsive personal portfolio website built using HTML and CSS.
The project demonstrates modern layout techniques, responsiveness,
animations, and a complete GitHub workflow.

## 🛠 Tech Stack
- HTML5
- CSS3
- Git & GitHub
- GitHub Pages

## ✨ Features
- Sticky navigation bar
- Hero section
- Flexbox cards
- Grid-based image gallery
- Responsive design (mobile, tablet, desktop)
- Hover effects and animations
- Contact form with validation


## 📚 What I Learned
- Responsive web design using media queries
- Flexbox and Grid layouts
- CSS animations and transitions
- GitHub workflow with branches and pull requests
- Hosting websites using GitHub Pages
